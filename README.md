# esp32-smart-farming-iot
An IoT-powered smart farming system designed for Japlak chili cultivation featuring real-time environmental monitoring, automated irrigation, MQTT communication, and Rule-Based decision making using ESP32 and Node-RED.

# Features
Real-time environmental monitoring
Automatic irrigation system
Rule-Based System (RBS) automation
MQTT communication protocol
Node-RED dashboard visualization
Google Sheets data logging
Manual and automatic pump control
Soil moisture monitoring
Rain detection system
Temperature and humidity monitoring

# Hardware Used
ESP32
DHT11 Sensor
DS18B20 Temperature Sensor
Capacitive Soil Moisture Sensor
MH-RD Rain Sensor
Relay Module
Mini Water Pump
Power Supply Module

# Software & Platform
Arduino IDE
Node-RED
MQTT Broker
Google Sheets API
ESP32 Board Package
